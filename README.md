# Brick Rigs Creation Interface 4 (Pre-release versions)

## Slow down and read this!
BRCI-4 is still in development. We do not recommend you using it yet. 

## What is BRCI?
Brick Rigs Creation Interface 4 is a python package written in python to create and edit creations in Brick Rigs.
It was specifically made to be accessible by anyone with little knowledge of Python.

## What should I know to use BRCI?
Many of you reading this are not developers, or don't know python at least.
To create basic things with BRCI, we recommend you learning the basics of python and object-oriented programming
(OOP). Then, take a look at our demos in the `Demos` folder.

## Information and support
Documentation can be found in the `doc` folder.
To learn more, report bug and suggest features, consider joining our discord: https://discord.gg/sZXaESzDd9

## Requirements

- Python 3.12 (3.13 may not be supported!)
- NumPy 2 or later

## Installation
It is (or soon will be) available on pip. To install it, run `pip install brci`. Then import it with `import brci`.
BRCI requires NumPy. You may install it with `pip install numpy`.
